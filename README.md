# City Explorer

## Descriere

Proiectul City Explorer este o pagină web simplă realizată pentru un laborator de Tehnologii Web. Scopul principal este să prezinte destinații turistice din România într-un layout clar, modern și ușor de navigat.

## Laborator

Laborator TW: 1

## Autor

Angelescu Mario

## Conținut

- antet cu numele site-ului și meniu de navigare
- secțiune cu destinații sub formă de carduri
- formular de planificare a unei călătorii
- secțiune cu recomandări utile pentru călătorie
- stilizare realizată exclusiv prin fișierul CSS

## Structură proiect

- index.html
- css/style.css

## Descriere tehnică

Pagina folosește HTML5 pentru structură și CSS pentru stilizare, inclusiv:

- Flexbox pentru antet
- Grid pentru cardurile de destinații
- responsive design pentru adaptarea la diferite dimensiuni de ecran
- pseudo-clase :hover și :focus pentru interactivitate

## Observație

Acest proiect este un exercițiu academic și are scop didactic.
